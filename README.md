# 🍱 SnackPass

SnackPass is a modern food ordering and discovery web application built with React and Vite.

## ✨ Features

- 🏠 Personalized home page
- 🔎 Explore food items
- 🍔 Food categories and menu
- 🛒 Shopping cart
- 🔔 Notifications and offers
- 🎟️ Discount vouchers
- ❤️ Favorite foods
- 📦 Order management
- 👤 User profile
- 🏆 Achievements and rewards
- 🌶️ Food preference filters
- ⭐ Food ratings
- 🖼️ Food images for menu items

## 🥗 Food Categories

SnackPass includes different categories such as:

- Snacks
- Dosa
- Lunch
- Noodles
- Chat
- Salads
- Drinks
- Milkshakes
- Desserts
- Cakes
